# 安装 MiSub 到桌面

MiSub 支持通过 Chrome 安装到手机桌面，以独立窗口打开。独立窗口保留系统状态栏和手势导航，但不显示浏览器的网站标题、域名和三点菜单。

## 安装步骤

1. 将当前版本部署到 HTTPS 网站。
2. 使用 Chrome 打开自己的 MiSub 域名，并完成登录。
3. 在 Chrome 菜单中选择“添加到主屏幕”，再选择“安装”（具体名称随 Chrome 版本变化）。
4. 从桌面的 MiSub 图标打开应用。

如果原来的桌面入口仍显示浏览器标题栏，先移除旧入口或卸载旧安装，再重新安装。

## 安装配置

- `index.html` 引用 `/manifest.webmanifest`，并使用 `crossorigin="use-credentials"` 携带登录凭据。
- manifest 使用稳定的 `id: "/"`、`start_url: "/"`、`scope: "/"` 和 `display: "standalone"`。
- 所有地址都相对于当前域名，适用于自定义域名和 Pages 域名。仪表盘及其导航页面均在安装范围内。
- `/icons/pwa/` 中的 192×192、512×512 图标使用相同底色和 Logo 比例，每张图片同时提供 `any maskable` 两种用途，避免普通图标与自适应图标之间的素材差异。图标 URL 使用固定版本参数更新缓存。
- 启用伪装时，manifest 和安装图标沿用品牌资源的访问规则，仅向已登录用户提供。建议从登录后的页面安装。

本次恢复的是安装能力，没有添加 Service Worker 或离线缓存。应用资源继续按现有网页更新方式加载。

## 启动页背景

Chrome 原生启动页、启动时的系统栏及网页深色背景使用 `#08090a`，与安卓安装图标的背景一致，减少交接时的底色变化。已安装的桌面图标和原生启动页不能通过网页代码可靠地实时跟随系统换色。

网页仅提供手动浅色、深色切换，保存的选择会继续保留，不读取或监听系统主题。未保存主题时使用固定浅色；旧的“跟随系统”记录会迁移为浅色。网页在 Vue 加载前应用保存的主题，避免深色模式启动时闪白。

Chrome 会保存已安装应用的启动配置。如果部署更新后启动页仍是旧颜色，重新安装桌面应用即可刷新启动配置。

如果在进入网页前图标出现一次跳动或缩放，先更新部署并重新安装，让启动器和 Chrome 使用同一版本的图标。图标与底色已统一，但部分 Android/Chrome 版本在原生窗口交接时，会因状态栏可视区域不同而出现位置变化。网页 CSS 不能直接调整原生启动图标的位置，也不能完全取消系统启动动画。

## 标题栏仍出现时

确认入口是安装应用，而非普通网页快捷方式，并检查是否跳转到了其他域名。跳转至安装范围外的地址时，Chrome 可能显示浏览器栏；manifest 不能隐藏外部网站的浏览器界面。
