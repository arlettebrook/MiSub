# UI 无障碍与多语言增强

本次增强参考 [上游提交 ce4e2891](https://github.com/imzyb/MiSub/commit/ce4e2891f453c2087d6d2465e44faa916c073875)，适配当前分支的登录验证、统一确认弹窗和移动端浮动控件。

- 图标按钮、搜索框、设置开关补充可翻译的无障碍名称；普通文字按钮默认不输出空的 `aria-label`。
- Toast 错误使用 `role="alert"` 和 `aria-live="assertive"`，其他通知使用 `role="status"` 和 `aria-live="polite"`。
- `Input` 将无障碍属性和原生事件传给输入框，通过 `aria-invalid`、`aria-describedby` 关联错误与调用方提示；布局类和样式保留在外层。
- `Switch` 将属性传给原生复选框，提供可见的键盘焦点；放大触控区域时，开关圆点仍相对轨道定位。
- 浅色主题提升辅助文字对比度，深色主题保留相应颜色；固定深色的日志区域保留浅色文字。
- `touch-target` 在粗指针设备下提供至少 44 × 44 px 的目标，`touch-target-min` 提供至少 24 × 24 px 的目标，导航按钮也按设备指针适配。
- 修复主题变量自引用，交互控件使用 `focus-visible` 焦点样式。
- 补全中英文翻译，合并重复字典项，避免翻译键或中文硬编码出现在英文界面。

新增回归检查覆盖控件语义、错误提示关联、通知播报、翻译键完整性及插值参数一致性。验证命令：

```sh
npm run test:run
npm run build
```

人工检查时，使用 Tab / Shift+Tab 遍历登录、订阅编辑与设置页面，用空格切换开关，并在中英文、明暗主题及触屏尺寸下检查名称、焦点、按钮区域和浮动控件布局。
