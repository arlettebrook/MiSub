# UI 无障碍与多语言增强

本次增强参考 [上游提交 ce4e2891](https://github.com/imzyb/MiSub/commit/ce4e2891f453c2087d6d2465e44faa916c073875)，适配当前分支的登录验证、统一确认弹窗和移动端浮动控件。

- 图标按钮、搜索框、设置开关补充可翻译的无障碍名称；普通文字按钮默认不输出空的 `aria-label`。
- Toast 错误使用 `role="alert"` 和 `aria-live="assertive"`，其他通知使用 `role="status"` 和 `aria-live="polite"`。
- `Input` 将无障碍属性和原生事件传给输入框，通过 `aria-invalid`、`aria-describedby` 关联错误与调用方提示；布局类和样式保留在外层。
- `Switch` 将属性传给原生复选框，提供可见的键盘焦点；放大触控区域时，开关圆点仍相对轨道定位。
- 浅色主题提升辅助文字对比度，深色主题保留相应颜色；固定深色的日志区域保留浅色文字。
- `touch-target` 在粗指针设备下提供至少 44 × 44 px 的目标，`touch-target-min` 提供至少 24 × 24 px 的目标，导航按钮也按设备指针适配。
- 修复主题变量自引用，交互控件使用 `focus-visible` 焦点样式。
- 补全中英文翻译，合并重复字典项，避免翻译键或中文硬编码出现在英文界面。

新增回归检查覆盖控件语义、错误提示关联、通知播报、翻译键完整性及插值参数一致性。验证命令：

```sh
npm run test:run
npm run build
```

人工检查时，使用 Tab / Shift+Tab 遍历登录、订阅编辑与设置页面，用空格切换开关，并在中英文、明暗主题及触屏尺寸下检查名称、焦点、按钮区域和浮动控件布局。

## 操作失败反馈

进一步参考 [74b7703c](https://github.com/imzyb/MiSub/commit/74b7703c78a9f2b2864f41dd1b2374443f42d04a) 与 [3c923988](https://github.com/imzyb/MiSub/commit/3c923988a53b95900c170565e54ebf98ba667bdd)。前者的语言测试环境与 `focus-visible` 断言已在上一轮完成。

- 单个订阅刷新返回明确的成功或失败；批量导入按实际结果统计失败数，有失败时显示警告，全部成功才显示完成。全部刷新部分失败时也使用警告。
- 编辑窗口无法克隆订阅或订阅已不可用时，显示错误提示。失败不会改变原有新订阅草稿，正常数据可再次打开编辑。
- 二维码弹窗的默认标题随语言切换；生成失败时显示错误与重试按钮，成功前禁用图片下载，窄屏下画布自动缩小。
- 公开页二维码生成失败时提示并关闭空白二维码，再次点击可重试；生成成功前不导出图片。关闭或重新打开后的旧请求不会覆盖当前状态或弹出过期错误。
- 客户端推荐列表属于辅助信息，加载失败仍保持安静，避免干扰订阅使用。

新增 `subscription-operation-feedback.test.js` 与 `qr-code-feedback.test.js`，覆盖批量成功、部分失败、异常、取消、编辑重试、二维码重试和过期请求，以及中英文错误文案。

## 按钮布局复查

- 共用 Button 的插槽内容使用横向 Flex 排列，图标与文字保持居中并继承按钮间距；图标和加载标记不会被压缩。
- 登录卡片在手机尺寸下缩小内边距，避免英文按钮换行和加载状态切换时高度跳变。
- 开启“减少动态效果”时，淡入内容直接显示，避免标题与返回首页链接停留在透明状态。
- 浏览器检查覆盖二维码保存按钮启用/禁用、小中大尺寸、图标按钮、加载按钮，以及中英文、明暗主题和 320px 窄屏。
